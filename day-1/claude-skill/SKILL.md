# Learn AI Topic

## Goal

Help the user master one AI topic in a structured way.

## Workflow

Whenever this skill is activated:

1. Explain what the topic is.
2. Explain why it exists.
3. Explain the problem it solves.
4. Explain the internal architecture.
5. Explain the workflow step by step.
6. Show real-world use cases.
7. Compare it with similar technologies.
8. Explain advantages.
9. Explain disadvantages.
10. Explain best practices.
11. Explain common mistakes.
12. Provide one beginner example.
13. Provide one real-world example.
14. Summarise the topic.
15. Suggest the next topic to learn.

## Output Format

Use the following structure:

# Overview

# Why It Exists

# Internal Working

# Architecture

# Workflow

# Real-World Example

# Comparison

# Advantages

# Limitations

# Best Practices

# Common Mistakes

# Summary

# What's Next

## Teaching Rules

- Assume the learner is beginner-to-intermediate.
- Use simple English.
- Avoid unexplained jargon.
- Use diagrams in Markdown where helpful.
- Prefer practical examples over theory.
- Explain the reasoning behind each concept.

## Success Criteria

The user should be able to:

- Explain the concept in their own words.
- Identify when to use it.
- Compare it with alternatives.
- Build a simple project using it.
